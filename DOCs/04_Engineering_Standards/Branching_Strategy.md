# Branching Strategy

**Document ID:** ENG-STD-007

## Permanent Branches

-   main: Production-ready code.
-   develop: Integration branch.

## Temporary Branches

-   feature/`<name>`{=html}
-   bugfix/`<name>`{=html}
-   hotfix/`<name>`{=html}
-   release/`<version>`{=html}
-   docs/`<topic>`{=html}

## Examples

feature/authentication bugfix/login-api hotfix/jwt-expiry release/v1.0.0
docs/api-spec
