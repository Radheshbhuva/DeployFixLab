# Git Commit Convention

**Document ID:** ENG-STD-008

## Format

`<type>`{=html}: `<short description>`{=html}

## Types

-   feat
-   fix
-   docs
-   refactor
-   test
-   chore
-   style
-   perf
-   ci

## Examples

feat: implement JWT authentication fix: resolve database connection
issue docs: update API specification refactor: simplify auth middleware
test: add login API tests ci: configure GitHub Actions

## Rules

-   Use imperative mood.
-   Keep first line under 72 characters.
-   One logical change per commit.
