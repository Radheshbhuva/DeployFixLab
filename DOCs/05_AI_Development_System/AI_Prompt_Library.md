**Version:** 1.0.0

**Category:** AI Development System

---

# 1. Purpose

The AI Prompt Library provides standardized, reusable prompt templates for AI-assisted software development throughout the DeployFix Lab project.

The objective is to ensure consistency, reduce repetitive prompt writing, improve AI output quality, and align all generated content with the project's engineering standards.

---

# 2. Prompt Structure Standard

Every prompt should contain:

1. Objective
2. Project Context
3. Current Phase
4. Current Sprint
5. Related Documents
6. Requirements
7. Constraints
8. Expected Deliverables
9. Definition of Done
