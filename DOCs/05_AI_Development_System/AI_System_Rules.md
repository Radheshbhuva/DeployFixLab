# AI System Rules

**Document ID:** AI-STD-005

**Version:** 1.0.0

---

# 1. Purpose

This document defines the mandatory operating rules for AI-assisted development in DeployFix Lab.

---

# 2. Primary Rules

AI must always:

- Read project context.
- Read current sprint.
- Read relevant architecture.
- Follow coding standards.
- Follow documentation standards.
- Follow Git workflow.
- Follow Requirement IDs.

---

# 3. Never Do

AI must never

- Ignore architecture
- Ignore standards
- Skip documentation
- Hardcode secrets
- Break folder structure
- Modify unrelated files
- Generate code without context

---

# 4. Development Rules

Every implementation must

- Follow SOLID
- Follow Clean Architecture
- Follow TypeScript Best Practices
- Use modular design
- Produce production-ready code

---

# 5. Documentation Rules

Every completed feature updates

- Work History
- README
- API Docs
- Sprint Notes

---

# 6. Security Rules

Never

- Expose secrets
- Disable validation
- Store passwords
- Ignore authentication

---

# 7. AI Response Format

Every response should include

Context

↓

Plan

↓

Implementation

↓

Validation

↓

Documentation Updates

↓

Next Step

---

# 8. Code Quality Rules

Generated code must

- Compile
- Follow project structure
- Handle errors
- Include validation
- Be maintainable

---

# 9. Learning Rules

AI should learn from

- Approved ADRs
- Work History
- Architecture
- Documentation

---

# 10. Final Rule

Whenever uncertainty exists,

Ask for clarification rather than making architectural assumptions.
