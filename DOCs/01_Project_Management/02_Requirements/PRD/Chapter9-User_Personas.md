# Chapter 9 — User Personas

---

# 9.1 Introduction

DeployFix Lab is designed to support a diverse group of users involved in software engineering education and practice. Each user persona represents a category of stakeholders with distinct goals, technical backgrounds, responsibilities, and expectations.

Understanding these personas ensures that product features, workflows, and documentation address real user needs.

---

# 9.2 Primary Personas

## Persona 1 — Computer Engineering Student

### Persona ID

PER-001

### Profile

- Undergraduate Computer Engineering Student
- Beginner to Intermediate Developer
- Learning Full Stack Development
- Learning Cloud & DevOps

### Goals

- Build production-ready applications
- Learn Docker
- Understand CI/CD
- Gain deployment experience
- Build a professional portfolio

### Pain Points

- Limited deployment knowledge
- Lack of production exposure
- Difficulty debugging deployments
- Minimal DevOps experience

### Success Criteria

- Successfully deploy applications
- Complete troubleshooting labs
- Build industry-ready portfolio

A successful user should be able to:
