# DeployFix Lab Glossary

  -----------------------------------------------------------------------
  Term                    Definition
  ----------------------- -----------------------------------------------
  ADR                     Architecture Decision Record

  API                     Application Programming Interface

  CI                      Continuous Integration

  CD                      Continuous Delivery / Deployment

  CRUD                    Create, Read, Update, Delete

  Docker                  Containerization platform

  Docker Compose          Multi-container orchestration tool

  JWT                     JSON Web Token

  Nginx                   Reverse proxy and web server

  ORM                     Object Relational Mapper

  Prisma                  Object-Relational Mapper used by DeployFix Lab to access PostgreSQL

  Prisma Migrate          Migration system used to manage database schema changes

  Prisma Studio           Developer GUI used to inspect and manage database records through the Prisma data model

  PostgreSQL              Relational database management system used by DeployFix Lab

  Supabase                Cloud platform used to host the managed PostgreSQL database for DeployFix Lab cloud environments

  Supabase PostgreSQL     Managed PostgreSQL database instance used by DeployFix Lab in cloud environments

  Supabase Dashboard /    Cloud administration interface used to inspect and manage the hosted Supabase PostgreSQL database
  Studio

  React                   Frontend JavaScript library

  Express                 Backend web framework

  Health Check            Endpoint indicating service status

  Root Cause Analysis     Process of identifying the fundamental cause of
  (RCA)                   an incident

  Incident                An unexpected event affecting application
                          availability or behavior

  Sprint                  Time-boxed development iteration

  DoD                     Definition of Done

  Repository              Git project containing source code

  Observability           Ability to understand system state using logs,
                          metrics, and traces

  DevOps                  Practices combining software development and
                          operations

  SRE                     Site Reliability Engineering

  Reverse Proxy           Server that forwards client requests to backend
                          services

  Volume                  Persistent Docker storage

  Bridge Network          Docker network enabling container communication
  -----------------------------------------------------------------------

## Naming Convention

-   Documents: Title_Case.md
-   Branches: feature/`<name>`{=html}, bugfix/`<name>`{=html},
    docs/`<name>`{=html}
-   Requirements: FR-001, NFR-001
-   Risks: R-001
-   ADRs: ADR-001
